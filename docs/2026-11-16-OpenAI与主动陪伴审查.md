# 桌边灯 OpenAI 接入与主动陪伴审查

2026-11-16 · 基线 GalAgent 1.0.1，提交 687876c。源码在 codex/galagent-openai-share 工作区。演示包用新建的示例存档，默认打开小栖，包含六页 PowerPoint、五分钟讲稿和可导入角色卡。

## 审查范围

把主程序的 111 份源码按调用方分开复核。范围覆盖 60 个核心文件、11 个主进程文件、6 个桌面观察文件、20 个界面文件、13 个共享文件和 1 个本地模型工作线程。界面生成字体清单做语法和本地路径检查，共 101 个字体链接。22 份内置像素小人通过格式检查，ID 无重复。另查了连接和启动入口、Windows 打包、Edge 浏览器桥接、接口相关测试和旧反代目录。历史 Live2D 原型、素材、依赖库和二进制发布物按历史资料、输入资产或依赖处理，未作其内部源码审计。

主动路径逐条从事件追到回复与存档。包括桌面窗体、截图、剪贴板、浏览器、程序恢复、任务结束、重逢、长时间无回应、关注事项、用户提醒、角色自设提醒、日常问候、记忆回访、晚一点补一句、研究分享、微信投递。核对了每条路径的开关、静音时段、专注和休息模式、频率限制、记录来源和关闭后的行为。

兴趣研究覆盖手动关注、聊天里提到的偏好、已核验的每日档案、经过授权的本机线索、网页和只读 MCP 来源、并行助手、汇总去重、来源回查、暂停、停止、重试、失效和重启后的状态。核对了模型和执行器换连接时的任务边界。

## 验收与仍待验证的边界

- 类型检查和 Windows 生产构建通过。全量测试共 371 项，370 项通过，1 项因平台条件跳过。
- Windows 实包跑通启动、明暗色界面、窄窗口、角色编辑和写卡指南、示例记忆纠正与静音。另在不同的隔离存档里跑通模型列表、直接聊天、执行器读取、换源后旧密钥不跟随。执行器 SSE 专项也通过了图片回传、文件写入、选择确认、计划审批、取消及重启续用。
- Windows 实包的提醒专项验证了改期后按新时间触发、只问一次、重启后保留结果与 JSON 回退。兴趣研究专项验证了心跳分享、停用兴趣、取消、失败后重试、MCP 资料来源及重启后回查。存档专项验证了强制退出后的聊天、记忆、设置和存档位置。双核心专项验证了后台档案及任务经注意力代理唤醒角色的完整路径。
- 最终构建的研究分享脚本有一次异常退出，随后两次用同一个实包和新测试存档复测均通过。异常退出原因未定位。
- Windows 剪贴板助手通过 C# 编译检查。使用受控输入检查了截屏时的切窗和剪贴板敏感标记，实包录音测试用合成音。真实剪贴板竞争、物理麦克风、微信账号和外部 MCP 平台尚未实测。
- 兼容格式的聊天、工具和后台研究使用本机模拟服务验收。另行检查 OpenAI 官方模型列表时，当前环境的凭据返回 HTTP 401。图片需要模型支持视觉，厂商专有视频格式只走对应供应商的接口。
- 旧版反代历史记录留在 Git 历史和历史文档。当前安装目录和个人存档未用于测试，运行分享请从独立启动入口进入。

协议参考 [OpenAI Chat Completions 接口](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。
