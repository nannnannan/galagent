# 活人感 v1：九个“更像真人”的主动交互，以及与每日档案、并发池的共存

## 1. 九个功能与代价

| 功能 | 实现 | 额外模型调用 |
|---|---|---|
| 分几条发 | 回复里用空行分段 → `Message.parts`（2–3 段，列表/代码/长段不拆），聊天页与气泡依次“打字”出现 | 0 |
| 偶尔补一句 | 回复 JSON 可选 `afterthought`，40–120 秒后作为一条普通消息补发；用户先开口、进入安静/休息即作废；≤1 次/20 分钟、≤8 次/天 | 0 |
| 心情与精力 | `runtime/core/vitality.ts`：精力跟作息曲线，心情回归基线；在场却被冷落 3 小时会委屈，聊天/摸头恢复；只把一句语气提示放进上下文 | 0 |
| 自己的小日程 | `runtime/shared/routine.ts`：角色卡 `routine` 或按“喜好”生成；头顶显示“在做什么”，午睡/睡觉时打盹 | 0 |
| 头顶小嘀咕 | 渲染器按前台**进程名类别**冒一句；停留 20 秒才触发、全局 4 分钟/同类 15 分钟冷却；不入库、不算主动 | 0 |
| 早安（含天气） | 生活时刻 `morning`，可用 `web_search` 查用户所在城市天气（不知道城市就不查），并接上昨天档案的“待续” | 1 次（计入主动额度） |
| 晚安 | 生活时刻 `goodnight`，过了“道晚安时间”用户仍在 → 说晚安后进入睡眠；任何互动叫醒（迷糊状态 20 分钟） | 1 次（计入主动额度） |
| 主动分享 | 生活时刻 `share`，按画像/记忆上网找新鲜事，找不到就保持安静；默认每天 1 次、间隔 ≥3 小时 | 1 次 + 工具轮（计入主动额度） |
| 旧事重提 / 回访 | 生活时刻 `recall`：2–21 天前的计划类记忆，每条只提一次；另：主角色聊天时用 `schedule_wakeup` 设事后回访；每日档案写完后为“待续”设一次下午 3 点回访 | 1 次（计入主动额度） |

## 2. 与并发限制共存

- **新增的模型调用只有生活时刻和回访闹钟**，全部走原有的 `generate(..., 'initiative')` → `request` → `callUpstream`，优先级 `attention`，受全局 20 路池约束；池为 chat/attention 预留 2 路，所以零点的档案作业（background）不会饿死晚安/早安。
- **同一时刻至多一个主动请求**：`lifeBlocked` 要求 `!lifeRunning && !deliveringSchedule && !busy && !wakeContext`，且执行器没有等待中的确认。
- **共用用户的节奏**：开始前先 `recordInitiative`（间隔、每小时、每天上限）；同时受 `attentionBlocked`（专注/休息、关闭主动、免打扰时段、临时安静、未配置、锁屏）、`proactiveTokens` 2 万 token 日预算、话题开关（早安与晚安 / 分享新鲜事 / 旧事重提）与“用户在电脑前”约束。
- **随机触发也节流**：分享/旧事每 20 分钟最多掷一次骰；失败后 20 分钟内不重试。
- 网页抓取（`web.ts`）不是模型请求，不占池槽位，但有 15–30 秒超时、≤5 跳、每跳隐私检查。
- 其余六项零模型调用，主进程 10 秒心跳里只做本地计算。

## 3. 与每日档案共存

- **一条回复一条记录**：分条只是 `parts` 展示字段，`text` 保留全文，档案指纹、`transcript`、记忆抽取都按一条消息处理；补一句是普通 `source: chat` 的助手消息，会进入当天档案。
- **小嘀咕从不入库**，不会污染档案或记忆。
- **早安等档案**：昨天的档案仍在生成时，早安最多等到 10:30，好让它能接上 `openThreads`；早安会读取昨天的档案“待续”。
- **档案驱动回访**：档案写完后（每日作业仍按日期唯一），若当天还早于 14:30，为一条待续设一个下午 3 点的角色闹钟（`followup-day` 防重复）；如果白天已经聊过，角色返回空 text 保持安静。
- **旧事重提强化记忆**：被提起的记忆 `recalls+1`，与遗忘曲线一致。
- **日记带心情**：每日档案请求附带 `myMoodTonight`，日记口吻与当天状态一致。
- 心情、生活时刻账本只存本地状态（`vitality`、`life-ledger`），不进入档案，不随存档导出。

## 4. 开关

「陪伴」页 →「像真人一样」：分几条发、偶尔补一句、心情与精力、自己的小日程、头顶小嘀咕（这五个是开关）；每天分享次数、旧事重提间隔天数、道晚安时间（可填任意值，核心收拢）。生活时刻仅在 `features.life`（桌面版开启）时运行。
