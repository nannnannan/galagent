## v1.1 · 全面放开

- **沙箱新增「完全放开」（full）**：全盘读写、命令与 MCP 都不再逐条询问、可访问内网与本机服务（`lanAccess`）、可读写凭据文件（`credentialFiles`）、前台命令最长 1 小时。选择时弹窗说明风险；离开该档自动关闭两个额外开关；默认仍是「标准」，「一键隐私锁定」照常切回严格。
- **始终保留**：GalAgent 自己的密钥文件与数据目录不可读写（`galagentSecret`）；你在「禁止访问的文件夹」里列出的目录；出站脱敏（独立开关，默认开）。
- **MCP 放开**：新增远程 Streamable HTTP（JSON 与 SSE 响应、`Mcp-Session-Id`、401 提示填授权头）；本地服务可设环境变量、远程服务可设请求头，值用系统加密（DPAPI）存在 `mcp-secrets.bin`，设置与界面只保留名称；本地服务看 Shell 开关，远程服务看联网开关；宽松 / 完全放开不再询问。
- **执行器单独配置**：可指定另一个模型（同一 API 地址）、单次输出上限（默认 8192，原 4096）、每个任务最多回合（默认 200，原 128）。
