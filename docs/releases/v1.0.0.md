# GalAgent 1.0.0

GalAgent 是住在 Windows 桌面上的 AI 像素伙伴。为 TA 选择性格和外形，接入自己的模型，从日常聊天开始慢慢熟悉彼此。TA 能记下你在意的事，跟进计划的变化，在合适的时候主动关心你，也会围绕你的兴趣查资料、带来新发现。需要帮忙时，可以授权 TA 处理本机任务；想安静一会儿，也随时可以暂停。

## 这次更新

- 后端按陪伴、记忆、研究、执行任务和工具职责整理，减少集中在单个服务里的逻辑。
- 同一件事支持改期、暂停和结束；主动关心保留用户原话来源，减少重复追问，避开不合适的打扰时机。
- 主动研究阅读网页正文、保留来源，支持追问、暂停和恢复关注。
- 任务完成后立即保存并汇报结果，长报告摘要在后台补充，不再卡住收尾和退出。
- 改进 OpenAI 兼容接口参数回退、错误提示和取消响应。
- 修复不同启动入口误用不同存档的问题，记住所选数据目录，显示自动保存时间，并验证异常退出后的恢复。

## 下载

- `GalAgent-Setup-1.0.0-x64.exe`：Windows x64 安装程序。
- `Mira-Proxy-0.0.771.zip`：可选 Mira 本地反代，含源码、使用说明与离线测试。默认 K3，需要自己的 Mira 登录态与额度；未知 Mira 程序版本会拒绝启动。
- `SHA256SUMS.txt`：上述文件的 SHA-256 校验值。

安装包未做可信发布者证书签名。升级前备份自己的数据目录；本版保留已记住的存档选择。Mira 反代包不包含本地 API Key、登录数据、日志、旧备份或 Mira 安装文件。
