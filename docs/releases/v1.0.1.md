# GalAgent 1.0.1 · 主动研究修复与 MCP 来源

这次更新解决了主动研究点击后长时间没有反馈的问题，并让研究可以使用你选定的 MCP 查询工具。

- 显示整理兴趣、查资料、等待对话和整理笔记等阶段；失败、没有新发现及完成都会说明。
- 支持停止本次研究，取消后迟到结果不会影响下一次任务。
- 「现在研究一下」可以重查近期兴趣，仍尊重用户暂停的兴趣。
- 缩短单轮兴趣规划，减少输出截断；无说明的 HTTP 400 和工具参数格式错误不再关闭后续工具能力。
- 在「连接 → MCP → 主动研究工具」选择服务声明为只读的工具。自动研究和手动研究复用相同选择，每轮最多两个 MCP 服务。
- MCP 查询与网页查询分开；笔记标注 MCP 来源，MCP 资料不进入网页助手的后续查询上下文。沿用现有权限与密钥存储。

验证：类型检查通过，358 项测试中 357 通过、1 项跳过。Windows 打包验收覆盖进度、停止、失败、重试、MCP 工具勾选、调用和来源显示；聊天、执行器和双核心验收通过。MCP 验收使用本地模拟服务，未验证所有第三方服务。

下载 `GalAgent-Setup-1.0.1-x64.exe` 升级，保留原存档选择。安装包未做可信发布者证书签名，升级前建议备份数据目录。Mira 反代沿用 1.0.0 发布页的可选适配包。
