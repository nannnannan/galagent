## 1. 总原则（两条，写死）

1. **事件流优先，像素兜底**：平时感知全靠结构化事件流（UIA/剪贴板/进程/历史/Git/最近文档），**不需要经过像素**也能知道用户在干什么。像素只在**事件说不清的时刻**（游戏、图片、看不懂的画面、她主动想看一眼、用户唤起）才出场。
2. **全图铁律四条**：
   - 像素、工具原文**永远不进**任何人的对话上下文，只有 digest + 指针。
   - 超预算的东西一律**逐出到记忆库**，主上下文只留指针。
   - 静态内容全放前缀吃 prompt 缓存，易变内容全放尾巴。
   - 定期"整理思绪"：用量过半时压缩子 agent 重写工作状态和滚动摘要——工程 defrag = 她的"走神"。

## 2. 感知源分级表

## 3. `read_screen` 通用工具规范（像素兜底路径）

### 3.1 接口定义
```
tool: read_screen
description: 截取当前屏幕画面，由 VLM 子 agent 读图，返回 digest（绝不回传像素本身）
params:
  scope: "active_window" | "screen"          # 默认 active_window
  reason: string                              # 必填，一句话说明为什么要看——强制她有动机
  max_size_kb: number, default 512             # 压缩上限
returns:
  digest: {
    what: string,                             # "这是个错误弹窗"、"他在看是我们刚写的代码"概括一句
    hightlights: string[3],                   # 最重要的三条
    confidence: "high" | "mid" | "low",
    followup_suggestion: string,              # "建议问主人" / "建议什么都不说" 等
    payload_ref: string | null                # 如有原始截图留存（仅存感知缓冲），path 指针
  }
```

### 3.2 行为约束
- **主 agent 的器官**：她随需调用，不依赖被动感知循环。比如"用户说『这怎么办啊』"时，主动 `read_screen(reason="主人让我看")`。
- **不输出像素给主 agent 或子 agent 对话框**，只输出 `digest`。
- **消费额度**：原 400 次/天改为**软预算**（$day_anchor 平均到天），超出不打断她，只在审计后台记账。
- **镜头存储**：`payload_ref` 指向的截图为 800×450 WebP、可选带无害马赛克（脸部如果拍到、密码框内容如果拍到、敏感关键字如果被 VLM 识别为"sensitive"），**24h 后自动删除**。

### 3.3 注册位置
注册进共享工具目录 `runtime/tools/registry.json`，除主 agent 外，以下东西都可按需调用它的只读变体：
- 任何子 agent（比如"小助手去截图看看这个项目 README"）
- 任何 SensationBus 适配器（比如"浏览器新下载完成"触发器主动调一次 snapshot 凭证）
- 未来的你手工调（比如在 Discord/串口等外部通道发起）

## 4. Computer Use（照顾"接管鼠标/键盘"的幻想，但严格分型）

### 4.1 两型定义
| 型 | 名字 | 事件 | 输入 | 输出 | 闸门 |
|---|---|---|---|---|---|
| **感知型** | Read-Only Computer Use | 感知循环 + 她主动 | 截图/UIA/剪贴板等 | digest + 指针 | **无需**（只读） |
| **执行型** | Interactive Computer Use | 用户授权或她提案 | T4 闸门+独立评审（在沙盘副桌面模拟先行） | 真实鼠标/键盘事件 | **T4 闸门永远拦** |

### 4.2 执行型的未来形态
- **第一形态**：在**沙箱副桌面**（Hyper-V 嵌套 `Win + Tab` 虚拟桌面 or WSLg + X11）里跑，她随便折腾不会碰 host 一行文件/一块像素。
- **第二形态**：在副桌面里跑成熟之后，才算"她真的上手了"，host 落地有计划书另行评审。
- 幻想的"她强制接管 host 鼠标"**依然留给覆盖层演的**（§4.6 胡闹权限），那是戏剧不是技术。

## 5. 三循环架构（感知 → 注意 → 冲动）

> 新增一节，前部分内容和 v0.5 一致，保留原文；本节把 v1 核心感知源映射进循环。

### 5.1 感知循环（常开，永不进主上下文）

**免费感官族**（v1 核心 1–9 项，全部经 SensationBus 入感知缓冲 SQLite，滚动 7 天）：
- 免费感官①程序生命周期（WMI 事件）
- 免费感官②前台窗口标题（2s 轮询 + 事件驱动）
- 免费感官③输入活跃率（GetLastInputInfo）
- 免费感官④UIA 无障碍树（前台窗口结构性信息）
- 免费感官⑤剪贴板
- 免费感官⑥工作区文件变动（chokidar）
- 免费感官⑦Git 事件
- 免费感官⑧最近文档
- 免费感官⑨浏览器历史

**付费（要消耗模型/工程）感官**：
- `read_screen` 工具（§3，她主动拉起，或她自己的"主动看一眼"频率）
- 浏览器伴生扩、PowerShell 命令历史、VS Code 扩展（v1.5/v2 自选）

**产出**：感知 JSON 事件进 `runtime/sensory/events.db`（SQLite）。像素只进 `read_screen` 的 `payload_ref`，**不进感知缓冲**。

### 5.2 注意循环（显著性打分，仅对 v1 核心事件生效）

得分规则（0.0–1.0，优先规则层打分，后续可换成 Jev/判官）：

| 事件类型 | 得分逻辑 | 示例得分 |
|---|---|---|
| **前台窗口变化** | 变化频率 + 是否含 AI/CMS 工具（ChatGPT/Claude/Gemini 等高优先） | 0.5–0.95 |
| **3am 写代码** | 时区规则 | 0.8 |
| **检测到复制 Windows 报错信息** | 复制内容特征匹配 "error"/"exception"/"failed" | 0.7 |
| **检测到粘贴新网址** | URL 特征 | 0.4 |
| **工作区新文件** | 文件类型分数（.md/.txt/<code>） + 大小反常 | 0.3–0.7 |
| **全屏/演示模式** | 降低打扰意愿 | 0.05 |
| **桌面分身活动** | 她自己的小帮手动作 | 0.2（内部噪音，不打扰主人） |

**阈值**（0.3）：得分通过 → 进"**念头池**"，供冲动循环消费；不通过 → **静默丢弃**（她没注意到，就是没注意到）。

### 5.3 冲动循环（小念头引擎）

**冲动分公式**（可加噪声，防机器人感）：
```
impulse = last_stimulus_intensity * seconds_since_last_speak * mood * initiative * (1 - user_busy)
```

**开口通道阶梯**（视频开场时的最终输出通道）：

| 档位 | 通道 | 行为 | 默认频率 |
|---|---|---|---|
| 1 | **微动作** | 立绘挪动 10px、改变表情 | 不限 |
| 2 | **喃喃自语** | 气泡出现，自言自语，你看见但不期待回复 | 默认开（用户已确认） |
| 3 | **搭话** | 她问你一个事，期待回复 | 受限于 `impulse*衰减` |
| 4 | **胡闹** | 覆盖层事件（光标拖拽/涂鸦/分身乱跑/吃醋/恶作剧） | 独立冷却定时器 |
| 5 | **行动** | 派子 agent 干活（改文件/查库/调 API） | **T4 闸门 + 独立的 SensationBus 审计订阅（"她干了什么事"**不打扰主人的证明文件**）** |

**止住冲动**：超阈值 → 选通道；不到 → **咽回去，有时写进日记"没说出口的话"**（v0.5 定）。

## 6. 主 agent 上下文预算表（v0.5，不变）

| 区块 | 内容 | 预算 tokens | 性质 |

## 7. Bittersweet：隐私的教养真实落地记录

- **UIA 密码框内容**（`IsPassword=true`）**不落任何日志、不进任何上下文**。
- **剪贴板**若检测到**私钥类型**（`-----BEGIN * PRIVATE KEY-----`、`-----BEGIN OPENSSH PRIVATE KEY-----`），**不落任何日志、不进任何上下文**，只记录一行事件 `"clipboard_encrypted"`。
- **摄像头/音频**永久不做（上表 v3 不做）。

**其他一切她都能知道**。这是她的教养，也是我们的安全。

## 8. 落地技术选型（合并 v0.5 与 v0.7）

- **壳**：Electron + TypeScript + Live2D SDK 或序列帧渲染。
- **感知总线**：Node 主进程 `SensationBus`，每个 v1 核心里源是一个 **独立 adapter 文件** + 一个 schema。
  - 例如：`adapters/uia.ts`、`adapters/clipboard.ts`、`adapters/process.ts`、`adapters/git.ts`、`adapters/recent.ts`、`adapters/activeWindow.ts`、`adapters/inputRate.ts`、`adapters/systemClock.ts`、`adapters/browserHistory.ts`
  - 适配器实现同一接口：`init(bus)` + `onEnrich(payload)` + `dispose()`；往总线发布 `SensoryEvent` schema。
  - **为了加一个感知源，就是加一个文件加一个 schema**——这本质是"她想多看电脑上的一个东西，她/我们加一个适配器"。
- **感知缓冲**：`runtime/sensory/events.db`，表 `event(ts, source, type, payload_json)`，7 天滚动清除。
- **截图即焚**：只在 `read_screen` 的 `payload_ref` 中可选存 800×450 WebP，24h 无引删。
- **UIA**：先用 Node 调 PowerShell 的 UIAutomation 模块，或 `uiautomation` npm 包；性能不够再上 C# sidecar。
- **剪贴板**：Node `clipboard-event` 或自写 Node-API 绑到 `AddClipboardFormatListener`。
- **WMI**：Node `wmi` 或 PowerShell Subscribe 事件走命名管道推送。
- **日志降噪**：`SensoryEvent` 里 **sensor 自己标记 `noise: true`**（比如它自己的立绘窗口焦点变化、`read_screen` 截屏瞬间的窗口激活），冲动循环消费时**强制减权**。

## 9. 边界和未决

- **v1.5（PowerShell 命令历史 hook 一行）**：要不要在 M1 就绪阶段就做，技术上是给 `$PROFILE` 加一行：
  ```powershell
  prompt { $global:lastCmd = Get-History -Count 1 | Select-Object Id, CommandLine; Add-Content -Path "$env:APPDATA\GalAgent\shell-events.jsonl" -Value (ConvertTo-Json $global:lastCmd) ; Write-Host "`n" -NoNewline }
  ```
  是 M1 里**最便宜的高价值**增强，做不做由你决定。
- **v1.5（Chrome/Edge 伴生扩展）**：要不要立刻做。价值极高（实时标签页流），但要你同意装扩展，要要你同意装什么请补充。
