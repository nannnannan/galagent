# 动态桌宠形体 v2 · 当前验收

用户本轮目标：制作可行、有存在感、活着的前端人物，真机完整测试与Kimi API放缓。本轮针对前端形体，旧完整首版的API、48h、资源目标等缺口仍保留。

## 已制作

默认启动只显示透明人物。头、躯干、发梢、披肩由不同的弹簧与局部网格权重控制；眼神跟随桌面鼠标并会闲置转开，眨眼局限眼部；触摸和拖动有局部反应与滞后。双击打开贴身短输入，Esc收起；菜单才打开长聊、记忆、连接。托盘单击与重复启动均显示人物，不自动跳固定页面。

保留原白发、K徽记、棱镜虹彩、深蓝星空披肩和七张差分。使用自有二维网格和局部素材混合，不是Cubism/Live2D rig；目前头发/披肩没有独立绘制层，极端转身和手臂新姿态不可凭网格创造。口动为文字演出，没有音频口型同步。

## 证据

- types/build与61项原核心、观察和IPC测试通过；新focus操作严格bool且仅pet发送者可用。
- tests/frontend/living-smoke.mjs：实际WebGL绘制、头/躯干/发梢运动分离、局部眨眼/文字口动、变形alpha命中；hidden/reduced停止循环，quiet保留微动；短输入中文composition确认不误发送。此项有明确UI fixture，不证明Kimi。
- 独立真实Electron与actual app.asar运行包：无Key、无生产会话，桌宠默认可见状态、辅助窗隐藏；12秒实际canvas录屏，180次真实draw通知间隔p95约17ms、中位16.7ms。只覆盖该可见窗口样本。最终版保留WebGL绘图缓冲区，防止录屏复制到已清除内容；12秒录像中97个内容采样全部含人物，不能只靠draw计数通过。
- Windows原生输入：双击短输入、Unicode中文文字实际进入、未配置发送保留草稿、Esc、实际拖动并保存-30/-22位置。Unicode注入不是物理拼音候选验证。见living-pet/native-interaction.json。
- 内部透明PNG、WebM与GIF在living-pet/。视频添加中性底色便于观看，应用窗口本身透明；GIF是录屏转码，不是生图动画。

## 原生捕获边界

同一个非交互透明窗口中，Windows捕获有时仅显示背后桌面；切换到交互/可聚焦状态时可捕获人物。相同窗口切回旧PNG也出现此现象，因此不能据空捕获认定新shader失效，也不能据draw计数宣称全桌面所有状态可见性已验收。保留为原生捕获/物理观察待核实项；未为截图强行改变默认焦点或取消点击穿透。
