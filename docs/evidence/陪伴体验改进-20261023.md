## 行为合同

- **语音**：较新的朗读替换较旧请求；停止、关闭朗读、切换模式、开始新对话后，迟到的合成或解码结果不能恢复播放。宿主取消 HTTP/SAPI 工作，渲染器停止 Web Audio、HTML Audio 和 Web Speech。聊天页、相处页和托盘均有停止入口。
- **目录保护**：配置非空禁止目录后，拒绝任意 Bash，拒绝多硬链接文件；搜索先枚举允许的文件，再交给 ripgrep，跳过禁止子树和目录链接。修改权限后取消旧任务。仍是应用内检查，不能宣称操作系统沙箱；未解决恶意外部进程在检查与使用之间替换路径的系统级竞态。无禁止目录时沿用完整访问。
- **日常陪伴**：沿用事件和模型判断，明确反馈参与后续判断。
- **专注时光**：停止主动开口和桌面小跑，保留用户主动对话；返回日常时立即重新判断尚未过期的待处理事件。
- **安静休息**：另暂停观察采集与自动朗读。保留原观察/语音开关，返回日常后按原设置工作。
- **反馈**：仅接受带真实事件类别的主动回复。喜欢/暂停某类提醒持久保存，可恢复默认；不会改变性格、关系或权限。暂停的事件类别不进入注意力评估。无来源的旧消息不伪造反馈入口。
- **兼容**：旧存档默认日常模式；新的模式和反馈可随相处存档导出、恢复。未承诺补齐原有关注列表、执行任务等完整迁移，自动备份和记忆时间线仍属后续候选。
