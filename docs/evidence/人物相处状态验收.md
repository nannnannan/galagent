# 人物相处状态与显隐验收

2026-10-09。按既定首版合同补齐六类微事件、心情、关系与小目标；保持人物素材、模型后端、观察范围与执行权限边界。

## 已实现的合同

| 场景 | 运行规则与证据 |
|---|---|
| E01 相遇与名字 | 首次成功聊天和身份提交，写稳定来源事件；同源重启不重复命名 |
| E02 找到位置 | 用户拖动有即时本地反应与摆放记录；模型反应请求首次后20分钟冷却，失败 / 取消也计尝试，跨重启保留 |
| E03 记住一件事 | 只有已提交、带来源的原句事实形成事件；札记不会晋升为事实，当前与历史事实分开 |
| E04 又见面 | 最新完成聊天间隔至少8小时，下一用户聊天或合格主动机会提供候选；先拖动不抢走资格，失败不消费，没有可靠线索保持未知 |
| E05 小小吃醋 | 新鲜可信AI程序标签或用户主动提到AI；每日资格、可关闭；两个触发都不证明外部聊天内容，浏览器标题不能猜AI工具 |
| E06 收住与修复 | 安静 / 纠正 / 关闭互动立即记录并生效，不扣关系；关吃醋后旧E05回复丢弃，普通无E05聊天可继续 |

事件有稳定 ID、时间与来源。长期四轴按来源去重、每日上限；连点与重复拖动不刷分。短期心情线性恢复并有结束时间，与长期关系分开；安静到期在观察关闭时也有确定状态通知。心情结束清除旧气泡，避免画面版本更新重播旧回答。

小目标进度来自真实摆放事件和现存来源合法札记，显示在“相处”页；不显示内部关系分数、情绪强度或事件 ID。旧版缺字段不编造进度，更新不重建聊天输入、设置控件或连接密钥草稿。没有声称模型知道实际屏幕坐标；摆放坐标仍由主进程保存。

## 记忆、恢复与隐私

- 语义和关键词候选都先按当前 / asOf / 明确历史视图过滤，再取前24，避免30次纠正后的旧索引挤掉当前事实。
- E04线索正文必须绑定事实及其源消息。删除后从事件、后续上下文和备份清除；旧格式缺来源存档会在导入前规范化。纠正保留历史事件，但当前上下文不再带旧线索正文。
- 私有模型消息依赖记录覆盖实际摘要、历史候选、选中事件与已重放消息的来源祖先；删除传播不遗漏这些来源。普通存档不含私有推理。
- 事件 / 来源类型冲突和无界心情等坏存档在事务副作用前拒绝；冷却能处理时钟回拨。恢复的同源事件不重复，删除账本防复活。

## 显隐与动画

此前本机实证：原生 chat 已隐藏，但 document.hidden 仍 false。现由主进程按 isVisible && !isMinimized 发布首次、show / hide / minimize / restore 状态；preload 严格 boolean；renderer 合并原生与 document 状态，订阅后查询，并防较晚初始查询覆盖新事件。

隐藏暂停呼吸、眨眼及伪元素，显示恢复；可见人物保持默认动画，不以关闭默认动态来降低 CPU。差分底层、自然眨眼恢复和逐像素命中继续通过。
