# 多阶段调色盘（GalAgent 版）

原写法用好感度变量 + EJS 条件切换阶段。GalAgent 没有好感度数值，改用**相处天数**（陪伴第 N 天，侧栏羁绊卡上的那个数）自动切换：角色卡的 `card.phases` 每一项写一个 `fromDays`，从那天起生效，最后一个已经开始的阶段就是当前阶段。

## 核心约束

- **底色不随阶段变化**：`card.base` 只写一次，放在阶段外。
- **通用衍生**写在 `card.derivations`（任何阶段都在）；**阶段专属衍生**写在对应 `phases[].derivations`，是该阶段**新出现**的行为，不是上一阶段衍生的升级版。
- 阶段的 `main` / `accents` 留空表示沿用通用的主色调 / 点缀；填写则在该阶段替换。
- 二次解释同理：通用的写 `card.notes`，阶段专属的写 `phases[].notes`。
- 同一行为在多阶段表现不同 → 归通用衍生，差异写进各阶段的二次解释。
- 引导作者自己写衍生和二次解释；不通顺、重复的内容保留原样。

## 引导流程

1. 确定底色（只写一次）。
2. 写第一阶段（通常 `fromDays: 0`）的主色调、点缀和专属衍生。
3. 问作者：哪些衍生是**始终如此**的（移到通用），哪些**只在这个阶段**（留在阶段里）。
4. 对每个后续阶段：主色调 / 点缀变不变？新出现了哪些行为？
5. 写通用二次解释，再写各阶段专属二次解释。不知道怎么写时反问：“你写了[某衍生]，AI 可能会怎么理解？你真正的意思是什么？”

## 示例

```json
"card": {
  "base": "好奇",
  "main": ["叛逆", "警惕"], "accents": ["不拘一格"],
  "derivations": [
    { "trait": "好奇", "text": "对新事物总是忍不住想要尝试，哪怕看起来很危险" }
  ],
  "phases": [
    { "name": "初识", "fromDays": 0, "main": [], "accents": [], "derivations": [
      { "trait": "警惕", "text": "从不主动分享个人信息，被问到时会反问“你为什么想知道”" } ], "notes": [] },
    { "name": "熟悉", "fromDays": 14, "main": ["热情", "试探"], "accents": [], "derivations": [
      { "trait": "试探", "text": "会故意说一些暧昧的话观察<user>反应，然后假装是开玩笑" } ], "notes": [
      { "topic": "试探", "text": "试探是因为害怕受伤……" } ] },
    { "name": "依赖", "fromDays": 60, "main": ["热情", "依赖"], "accents": ["温柔"], "derivations": [], "notes": [] }
  ]
}
```

## 自查清单

- [ ] 底色只写一次，不在阶段里
- [ ] 阶段 `fromDays` 递增、互不重复，第一个阶段从 0 开始
- [ ] 阶段专属衍生是新行为，不是升级版
- [ ] 通用衍生 / 二次解释放在阶段外
- [ ] 衍生与二次解释由作者本人写
