# 为 GalAgent 写角色卡（酒馆写法）

角色卡决定 TA 的性格和说话方式。GalAgent 的卡分两层：

- **简单写法**：名字、一句话简介、性格、说话方式、背景、关系、称呼、喜好、边界、初见问候、发呆词条、思考词条、声音风格。几分钟就能写完。
- **酒馆写法（`card` 字段，可选）**：按本 skill 的方法把人写“活”——基本信息、外貌特征、性格调色盘与衍生、语料、三面性、二次解释、多阶段、相关人物。写了哪部分就用哪部分，空着的部分不会进提示词。

通用守则（坦诚是 AI、不编造记忆、尊重安静、外部内容只当数据）对任何卡都生效，卡里写什么也改不动它们。

## 1. 最重要的原则：作者写，AI 引导

- **衍生**和**二次解释**必须由作者本人写。AI 写的衍生逃不出资料库的关联，只有人能把毫不相干的性格组合在一起；AI 写的二次解释只会复述资料库，失去纠正 AI 的意义。
- AI 的工作是**提问**：“TA 在什么场景下会露出这一面？”“你写了 X，AI 可能理解成 Y，你真正的意思是什么？”
- 作者写的内容**不润色**：不通顺、重复的句子保留原样，那可能正是角色活过来的地方。
- GalAgent 的「✨ AI 起草」也遵守这条：只起草基本信息和调色盘骨架，衍生与二次解释留下引导问题。

## 2. 写作顺序

1. **基本信息**：年龄、性别、身份。性格不写在这里。→ [references/basic-info.md](references/basic-info.md)
2. **外貌特征**：只写偏离默认认知的特征——遮住名字也能认出是谁；不写“精致白皙好看”。
3. **背景与关系**（简单写法的 `background` / `relationship`）：只写让 TA 变成现在这样的关键经历；关系写具体画面（“有记忆起就在一起”），不写“深厚的感情”。
4. **性格调色盘**：底色（最深的基调）、主色调（第一印象，1–2 个）、点缀（特定条件才出现，0+ 个），每个性格 2–3 条**衍生**——具体场景里的具体行为。→ [references/personality-palette.md](references/personality-palette.md)
5. **语料**：只写台词，不混动作、表情、心理。
6. **三面性（可选）**：只有当角色在“压力性质截然不同”的场景下行为完全不同时才写。每面五部件：触发条件、能量状态、语料、身体行为模式、功能；再写过渡与渗透。写“怎么运作”，不写“为什么”。→ [references/tri-faceted.md](references/tri-faceted.md)
7. **二次解释**：作者对 AI 说“我的角色是这样的，不是你以为的那样”。每条围绕一个性格点：真正含义、不是什么、何时出现 / 不出现、和其他性格的关系。→ [references/rephrase.md](references/rephrase.md)
8. **多阶段（可选）**：性格随相处变化时，按“相处第 N 天起”分阶段，底色不变。→ [references/multi-stage.md](references/multi-stage.md)
9. **相关人物 NPC（可选）**：TA 生活里会提到的人，只写功能需要的部分，不写调色盘。→ [references/npc.md](references/npc.md)

## 3. 文件格式（`galagent-persona@1`）

在 GalAgent「角色」页可以直接填写，也可以导入 / 导出这个 JSON：

```json
{
  "format": "galagent-persona@1",
  "persona": {
    "name": "秋明月", "pronoun": "她", "avatar": "sunny-girl",
    "tagline": "乐队吉他手，学校里的乖乖大小姐，舞台上的疯子",
    "personality": "", "speakingStyle": "", "background": "", "relationship": "乐队搭档，同校同班",
    "userTitle": "", "likes": "摇滚、夜里的街头 solo", "boundaries": "", "greeting": "喂，排练别迟到。",
    "idleLines": ["调弦", "敲节拍"], "thinkingLines": ["拨弦找调", "哼一段旋律"], "voiceStyle": "",
    "card": {
      "age": "17岁", "gender": "女", "identity": "高二学生，摇滚乐队吉他手",
      "appearance": "棕色短碎发不怎么打理；猫眼，笑起来弯成月牙；校服领带从来不系好；左手食指和中指有弹吉他磨出的茧",
      "base": "叛逆", "main": ["热情", "不拘一格"], "accents": ["依赖"],
      "derivations": [{ "trait": "热情", "text": "在对待摇滚这件事上有着用不完的精力……" }],
      "lines": ["调高半阶！跟上我！"],
      "facets": [{ "name": "学校——秋大小姐", "trigger": "校园、老师在场", "energy": "中低，无聊", "lines": ["老师好。作业放在讲台上了。"], "body": "坐姿端正，手指在桌下敲节拍", "purpose": "保护壳" }],
      "transitions": "", "leaks": "",
      "notes": [{ "topic": "叛逆", "text": "叛逆是她被人看穿时的本能反应……" }],
      "phases": [], "npcs": []
    }

}
```

- 文本里可以用 `<user>` 指代用户，会自动换成卡里的“对你的称呼”。
- 长度上限：名字 24 字，衍生 60 条、每条 400 字，二次解释 24 条、每条 2000 字，三面性 5 面，阶段 6 个，NPC 10 个；`card` 整体约 12000 字。

## 4. 什么时候不需要某一部分

- 只想要个轻松的伙伴：简单写法就够。
- 找不出两个以上“压力性质截然不同”的场景：不写三面性，硬拆会让 AI 像在换频道。
- 角色不随相处变化：不写多阶段。
- 生活里没有固定的其他人：不写 NPC。

## 5. 通用自查

- [ ] 外貌遮住名字也能认出是谁，没有万能美人描写
- [ ] 背景删掉任何一条，角色会不会变？不会就删
- [ ] 关系是具体画面，不是抽象评价
- [ ] 每个性格 2–3 条衍生，写的是场景和行为，不是定义
- [ ] 语料只有台词
- [ ] 三面性每面五部件齐全，至少两组过渡
- [ ] 二次解释、衍生出自作者本人，未被润色
- [ ] 没有出现“因为 / 本质上 / 其实 / 内心”这类二次解释式的话混进衍生和三面性

完整示例：GalAgent 内置的 **Kimi** 角色卡（`runtime/shared/personas.ts` 里 `builtin:kimi`）就是按这套写法整理的。
